### 1.2.34 确保邮件传输代理配置为仅本地模式

**级别：** 要求

**适用版本：** 全部

**规则说明：**

邮件传输代理（MTA）默认可能监听所有网络接口，对外提供邮件收发服务。对于非邮件服务器，应将MTA配置为仅监听本地回环地址，避免暴露不必要的网络服务。攻击者可利用开放监听的邮件服务进行未授权的中继发送或信息探测。

openEuler默认安装postfix作为MTA，且默认配置为仅本地模式。

**规则影响：**

配置为仅本地模式后，系统将无法接收来自外部网络的邮件，仅能处理本机邮件。

**检查方法：**

- 使用如下命令检查postfix是否配置为仅监听本地回环地址，如果返回值为"loopback-only"，表示配置正确：

  ```bash
  # postconf inet_interfaces
  inet_interfaces = loopback-only
  ```

- 也可通过如下命令确认postfix仅监听本地回环地址：

  ```bash
  # ss -plntu | grep 25
  LISTEN  0  100  127.0.0.1:25  0.0.0.0:*
  ```

**修复方法：**

编辑/etc/postfix/main.cf文件，修改或添加如下配置：

```bash
inet_interfaces = loopback-only
```

修改完成后，重启postfix服务使配置生效：

```bash
# systemctl restart postfix.service
```
