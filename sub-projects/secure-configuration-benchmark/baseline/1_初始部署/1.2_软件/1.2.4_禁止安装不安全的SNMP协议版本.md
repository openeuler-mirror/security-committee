### 1.2.4 禁止安装不安全的SNMP协议版本

**级别：** 要求

**适用版本：** 全部

**规则说明：** 

简单网络管理协议（SNMP，Simple Network Management Protocol），是专门设计用于在IP网络中管理网络节点的一种标准协议，该协议允许网元之间传递相关网络管理、控制数据。对于不需要SNMP的场景，如果安装了SNMP，则增加了系统资源消耗，并扩大了攻击面，特别是如果使用了SNMP v1.0协议，将导致攻击者可以轻易窃取、篡改、伪造SNMP报文，对各网元进行攻击。

如需使用SNMP服务，应使用SNMPv3版本，其提供用户认证和数据加密功能，安全性远高于v1/v2c。

openEuler安装镜像中提供了net-snmp安装包，但默认未安装。

**规则影响：**

依赖于SNMP v1/v2c服务的程序执行受限制。

**检查方法：** 

- 检查是否安装了net-snmp，如果命令返回为空，则表示未安装，无需后续检查：

```bash
# rpm -qa | grep -E "net-snmp-[0-9]"
```

- 如果已安装，检查SNMP配置中是否使用了不安全的协议版本（v1或v2c），以下命令应无输出：

```bash
# grep -E "^[^#]*(rocommunity|rwcommunity)" /etc/snmp/snmpd.conf
```

若输出中包含rocommunity或rwcommunity配置，则表示使用了不安全版本。

**修复方法：** 

对于使用不安全SNMP版本（v1或v2c）的场景，选择以下方式之一：

- 如果不需要SNMP服务，卸载net-snmp：

```bash
# yum remove net-snmp
```

或

```bash
# dnf remove net-snmp
```

- 如果需要SNMP服务，应改用SNMPv3，删除不安全的社区字符串配置，配置v3用户：

```bash
# vim /etc/snmp/snmpd.conf
# 删除或注释rocommunity/rwcommunity行
# 添加SNMPv3用户，例如：
createUser authOnlyUser SHA "authpass123" AES "privpass123"
rouser authOnlyUser
# systemctl restart snmpd
```
