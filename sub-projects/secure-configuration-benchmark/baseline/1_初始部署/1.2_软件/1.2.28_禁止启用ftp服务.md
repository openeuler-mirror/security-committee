### 1.2.28 禁止启用ftp服务

**级别：** 要求

**适用版本：** 全部

**规则说明：**

FTP（File Transfer Protocol，文件传输协议）是一种传统的文件传输服务。FTP协议本身不支持加密传输，且在默认配置下允许匿名用户连接访问，容易导致信息泄露和恶意文件上传等安全问题。除非系统明确被指定为FTP服务器，否则建议移除FTP服务端软件包，以减少潜在的攻击面。如业务需要进行文件传输，可以通过SFTP进行替代。

openEuler默认未安装FTP服务端软件包vsftpd。

**规则影响：**

移除FTP服务后，系统将无法对外提供FTP文件传输服务。

**检查方法：**

- 使用如下命令检查是否安装了vsftpd软件，如果命令返回为"package vsftpd is not installed"，表示未安装：

  ```bash
  # rpm -q vsftpd
  package vsftpd is not installed
  ```

- 如果vsftpd已安装，可通过如下命令检查vsftpd服务是否未启用：

  ```bash
  # systemctl is-enabled vsftpd.service
  disabled
  ```

**修复方法：**

对于已安装vsftpd的系统，可以通过yum或dnf命令进行卸载：

```bash
# yum remove vsftpd
```
或
```bash
# dnf remove vsftpd
```
