### 1.2.26 禁止启用autofs服务

**级别：** 要求

**适用版本：** 全部

**规则说明：** 

autofs允许自动挂载设备，通常包括 CD/DVD 和 USB 驱动器。启用自动挂载功能后，任何具有物理访问权限的人都可以插入 USB 驱动器或光盘，其内容即可在系统中使用，即使他们本身没有权限来手动挂载该设备。

禁用autofs服务以减少潜在的攻击面。

**规则影响：**

NA

**检查方法：**

检查是否启动了服务，如果命令返回为disable，则表示服务未启动：

```bash
# systemctl is-enabled autofs.service
disabled
```

**修复方法：**

对于已安装autofs组件的服务器，可以禁用autofs服务：

```bash
# systemctl --now disable autofs.service
```
