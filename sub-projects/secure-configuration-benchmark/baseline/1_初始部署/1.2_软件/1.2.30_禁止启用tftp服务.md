### 1.2.30 禁止启用tftp服务

**级别：** 要求

**适用版本：** 全部

**规则说明：**

TFTP（Trivial File Transfer Protocol，简单文件传输协议）是一种轻量级的文件传输协议，与FTP不同，TFTP不提供身份认证和加密机制，任何人都可以通过TFTP协议读取或上传文件，容易导致敏感信息泄露和恶意文件植入。除非系统明确需要提供TFTP服务（如PXE网络启动场景），否则建议移除该软件包，以减少潜在的攻击面。

openEuler默认未安装tftp-server软件包。

**规则影响：**

移除TFTP服务后，系统将无法对外提供TFTP文件传输服务，依赖TFTP的PXE网络启动等功能将不可用。

**检查方法：**

- 使用如下命令检查是否安装了tftp-server软件，如果命令返回为"package tftp-server is not installed"，表示未安装：

  ```bash
  # rpm -q tftp-server
  package tftp-server is not installed
  ```

- 如果tftp-server已安装，可通过如下命令检查tftp服务是否未启用：

  ```bash
  # systemctl is-enabled tftp.service
  disabled
  ```

**修复方法：**

对于已安装tftp-server的系统，可以通过yum或dnf命令进行卸载：

```bash
# yum remove tftp-server
```
或
```bash
# dnf remove tftp-server
```
