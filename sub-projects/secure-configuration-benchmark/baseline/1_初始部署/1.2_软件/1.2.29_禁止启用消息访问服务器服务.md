### 1.2.29 禁止启用消息访问服务器服务

**级别：** 要求

**适用版本：** 全部

**规则说明：**

消息访问服务器（如dovecot）提供IMAP和POP3邮件收取服务，使远程用户可以访问服务器上的邮件。除非系统明确被指定为邮件服务器，否则建议移除该软件包，以减少潜在的攻击面。攻击者可利用消息访问服务的漏洞获取未授权访问，或通过暴力破解获取用户邮件内容。

openEuler默认未安装dovecot软件包。

**规则影响：**

移除消息访问服务器后，系统将无法对外提供IMAP和POP3邮件收取服务。

**检查方法：**

- 使用如下命令检查是否安装了dovecot软件，如果命令返回为"package dovecot is not installed"，表示未安装：

  ```bash
  # rpm -q dovecot
  package dovecot is not installed
  ```

- 如果dovecot已安装，可通过如下命令检查dovecot服务是否未启用：

  ```bash
  # systemctl is-enabled dovecot.service
  disabled
  ```

**修复方法：**

对于已安装dovecot的系统，可以通过yum或dnf命令进行卸载：

```bash
# yum remove dovecot
```
或
```bash
# dnf remove dovecot
```
