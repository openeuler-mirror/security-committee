### 1.2.27 禁止启用dnsmasq服务

**级别：** 要求

**适用版本：** 全部

**规则说明：** 

dnsmasq是一个轻量级工具，提供 DNS 缓存、DNS 转发以及 DHCP（动态主机配置协议）服务。除非系统被明确指定为DNS缓存、DNS转发和DHCP服务器，否则建议删除该软件包，以减少潜在的攻击面。

**规则影响：**

NA

**检查方法：**

检查是否启动了服务，如果命令返回为disable，则表示服务未启动：

```bash
# systemctl is-enabled dnsmasq.service
disabled
```

**修复方法：**

对于已安装dnsmasq组件的服务器，可以禁用dnsmasq服务：

```bash
# systemctl --now disable dnsmasq.service
```
