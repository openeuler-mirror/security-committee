### 1.2.33 禁止启用xinetd服务

**级别：** 要求

**适用版本：** 全部

**规则说明：**

xinetd是一个超级服务守护进程，用于统一管理多个网络服务的启动和连接。xinetd本身存在安全风险，且其管理的服务通常已改用独立守护进程或systemd管理。除非有明确的兼容性需求，否则建议移除该软件包，以减少潜在的攻击面。

openEuler默认未安装xinetd软件包。

**规则影响：**

移除xinetd后，依赖xinetd托管的网络服务将无法通过xinetd启动。

**检查方法：**

- 使用如下命令检查是否安装了xinetd软件，如果命令返回为"package xinetd is not installed"，表示未安装：

  ```bash
  # rpm -q xinetd
  package xinetd is not installed
  ```

- 如果xinetd已安装，可通过如下命令检查xinetd服务是否未启用：

  ```bash
  # systemctl is-enabled xinetd.service
  disabled
  ```

**修复方法：**

对于已安装xinetd的系统，可以通过yum或dnf命令进行卸载：

```bash
# yum remove xinetd
```
或
```bash
# dnf remove xinetd
```
