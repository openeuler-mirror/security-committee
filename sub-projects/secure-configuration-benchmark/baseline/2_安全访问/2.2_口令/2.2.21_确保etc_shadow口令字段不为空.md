### 2.2.21 确保/etc/shadow口令字段不为空

**级别：** 要求

**适用版本：** 全部

**规则说明：**

/etc/shadow文件中用户口令字段为空表示该用户无需口令即可登录，等同于空口令登录，存在严重安全风险。应确保所有可登录用户的口令字段不为空。

openEuler默认满足此要求。

**规则影响：**

无

**检查方法：**

使用如下命令检查是否有口令字段为空的可登录账号，以下命令应无输出：

```bash
# awk -F: 'NR==FNR{shell[$1]=$7;next} ($2 == "" && shell[$1] !~ /(nologin|false)$/) {print $1}' /etc/passwd /etc/shadow
```

**修复方法：**

对于口令字段为空的账号，使用如下命令设置口令：

```bash
# passwd <username>
```

或锁定该账号：

```bash
# passwd -l <username>
```
