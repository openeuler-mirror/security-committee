### 2.2.12 确保口令修改时字符变化数量设置正确

**级别：** 要求

**适用版本：** 全部

**规则说明：**

difok参数用于设置新口令与旧口令之间必须不同的字符数量。如果新口令与旧口令的差异字符数少于该值，则新口令将被拒绝。合理配置该参数可以防止用户仅对口令做微小修改，降低口令被猜测的风险。

建议difok设置为不小于5。

**规则影响：**

无法设置与旧口令过于相似的新口令。

**检查方法：**

- 在/etc/pam.d/system-auth文件中检查pam_pwquality的difok配置：

  ```bash
  # grep pam_pwquality /etc/pam.d/system-auth
  password    requisite     pam_pwquality.so minlen=8 minclass=3 difok=5 enforce_for_root try_first_pass local_users_only retry=3 dcredit=0 ucredit=0 lcredit=0 ocredit=0
  ```

- 也可在/etc/security/pwquality.conf文件中检查difok配置：

  ```bash
  # grep "^difok" /etc/security/pwquality.conf
  difok = 5
  ```

**修复方法：**

方法1：
- 在/etc/pam.d/system-auth和/etc/pam.d/password-auth文件中，为pam_pwquality.so添加或修改difok参数：

  ```bash
  # vim /etc/pam.d/system-auth
  password    requisite     pam_pwquality.so minlen=8 minclass=3 difok=5 enforce_for_root try_first_pass local_users_only retry=3 dcredit=0 ucredit=0 lcredit=0 ocredit=0
  ```

方法2：
- 在/etc/security/pwquality.conf文件中配置：

  ```bash
  # vim /etc/security/pwquality.conf
  difok = 5
  ```
