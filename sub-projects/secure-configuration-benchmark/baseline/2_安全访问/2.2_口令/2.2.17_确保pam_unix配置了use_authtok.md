### 2.2.17 确保pam_unix配置了use_authtok

**级别：** 要求

**适用版本：** 全部

**规则说明：**

use_authtok参数使pam_unix模块使用前序模块（如pam_pwquality）已验证通过的新口令，而不提示用户输入口令。配置该参数可以确保口令修改流程中，pam_unix不会绕过前序口令质量检查直接设置口令，保证口令复杂度等规则得到强制执行。

**规则影响：**

无

**检查方法：**

- 在/etc/pam.d/system-auth文件中检查pam_unix的password行是否包含use_authtok：

  ```bash
  # grep "password.*pam_unix" /etc/pam.d/system-auth
  password    sufficient    pam_unix.so sha512 shadow try_first_pass use_authtok
  ```

- 在/etc/pam.d/password-auth文件中检查pam_unix的password行是否包含use_authtok：

  ```bash
  # grep "password.*pam_unix" /etc/pam.d/password-auth
  password    sufficient    pam_unix.so sha512 shadow try_first_pass use_authtok
  ```

**修复方法：**

编辑/etc/pam.d/system-auth和/etc/pam.d/password-auth文件，为pam_unix.so的password行添加use_authtok参数：

```bash
# vim /etc/pam.d/system-auth
password    sufficient    pam_unix.so sha512 shadow try_first_pass use_authtok
```

```bash
# vim /etc/pam.d/password-auth
password    sufficient    pam_unix.so sha512 shadow try_first_pass use_authtok
```
