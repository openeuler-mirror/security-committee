### 2.2.14 确保口令中最大顺序字符数设置正确

**级别：** 要求

**适用版本：** 全部

**规则说明：**

maxsequence参数用于限制口令中允许出现的最大顺序字符数（如"abcd"、"1234"等递增或递减序列）。如果口令中包含超过该长度的顺序字符序列，则口令将被拒绝。配置该参数可以防止用户使用常见的键盘序列或数字序列，降低口令被猜测的风险。

建议maxsequence设置为不大于3。

**规则影响：**

无法设置包含过长顺序字符序列的口令。

**检查方法：**

- 在/etc/pam.d/system-auth文件中检查pam_pwquality的maxsequence配置：

  ```bash
  # grep pam_pwquality /etc/pam.d/system-auth
  password    requisite     pam_pwquality.so minlen=8 minclass=3 maxsequence=3 enforce_for_root try_first_pass local_users_only retry=3 dcredit=0 ucredit=0 lcredit=0 ocredit=0
  ```

- 也可在/etc/security/pwquality.conf文件中检查maxsequence配置：

  ```bash
  # grep "^maxsequence" /etc/security/pwquality.conf
  maxsequence = 3
  ```

**修复方法：**

方法1：
- 在/etc/pam.d/system-auth和/etc/pam.d/password-auth文件中，为pam_pwquality.so添加或修改maxsequence参数：

  ```bash
  # vim /etc/pam.d/system-auth
  password    requisite     pam_pwquality.so minlen=8 minclass=3 maxsequence=3 enforce_for_root try_first_pass local_users_only retry=3 dcredit=0 ucredit=0 lcredit=0 ocredit=0
  ```

方法2：
- 在/etc/security/pwquality.conf文件中配置：

  ```bash
  # vim /etc/security/pwquality.conf
  maxsequence = 3
  ```
