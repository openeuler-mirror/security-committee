### 2.2.16 禁止pam_unix使用历史口令记忆功能

**级别：** 建议

**适用版本：** 全部

**规则说明：**

pam_unix模块的remember参数用于在/etc/security/opasswd文件中记录用户的历史口令。该功能已由pam_pwhistory模块提供更完善的实现，如果同时配置pam_unix的remember参数和pam_pwhistory模块，可能导致口令历史检查逻辑冲突。应确保pam_unix模块未配置remember参数，口令历史检查统一由pam_pwhistory模块处理。

**规则影响：**

无

**检查方法：**

- 使用如下命令检查pam_unix模块是否配置了remember参数，以下命令应无输出：

  ```bash
  # grep "pam_unix.*remember" /etc/pam.d/system-auth /etc/pam.d/password-auth
  ```

**修复方法：**

编辑/etc/pam.d/system-auth和/etc/pam.d/password-auth文件，删除pam_unix.so行中的remember参数。例如：

修改前：

```bash
password    sufficient    pam_unix.so sha512 shadow remember=5 try_first_pass use_authtok
```

修改后：

```bash
password    sufficient    pam_unix.so sha512 shadow try_first_pass use_authtok
```
