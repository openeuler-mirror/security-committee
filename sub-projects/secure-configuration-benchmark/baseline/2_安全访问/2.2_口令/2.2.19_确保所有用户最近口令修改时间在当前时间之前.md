### 2.2.19 确保所有用户最近口令修改时间在当前时间之前

**级别：** 要求

**适用版本：** 全部

**规则说明：**

用户口令的最近修改时间应早于当前时间。如果口令修改时间在未来，说明口令修改记录异常，可能导致口令策略（如有效期、过期锁定等）失效，使账号长期处于不受控状态。

openEuler默认满足此要求。

**规则影响：**

无

**检查方法：**

使用如下命令检查是否有用户的口令最近修改时间在未来，以下命令应无输出：

```bash
# awk -F: '($3 != "" && $3 > strftime("%s")/86400) {print $1}' /etc/shadow
```

**修复方法：**

对于口令修改时间异常的账号，使用如下命令强制用户下次登录时修改口令：

```bash
# chage -d 0 <username>
```

或直接为该账号设置新的口令：

```bash
# passwd <username>
```
