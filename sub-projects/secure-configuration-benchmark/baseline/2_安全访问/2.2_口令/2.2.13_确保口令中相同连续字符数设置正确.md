### 2.2.13 确保口令中相同连续字符数设置正确

**级别：** 要求

**适用版本：** 全部

**规则说明：**

maxrepeat参数用于限制口令中允许出现的相同字符最大连续次数。如果口令中同一字符连续出现次数超过该值，则口令将被拒绝。配置该参数可以防止用户使用如"aaa"、"1111"等重复字符组合，降低口令被暴力破解的风险。

建议maxrepeat设置为不大于3。

**规则影响：**

无法设置包含过多相同连续字符的口令。

**检查方法：**

- 在/etc/pam.d/system-auth文件中检查pam_pwquality的maxrepeat配置：

  ```bash
  # grep pam_pwquality /etc/pam.d/system-auth
  password    requisite     pam_pwquality.so minlen=8 minclass=3 maxrepeat=3 enforce_for_root try_first_pass local_users_only retry=3 dcredit=0 ucredit=0 lcredit=0 ocredit=0
  ```

- 也可在/etc/security/pwquality.conf文件中检查maxrepeat配置：

  ```bash
  # grep "^maxrepeat" /etc/security/pwquality.conf
  maxrepeat = 3
  ```

**修复方法：**

方法1：
- 在/etc/pam.d/system-auth和/etc/pam.d/password-auth文件中，为pam_pwquality.so添加或修改maxrepeat参数：

  ```bash
  # vim /etc/pam.d/system-auth
  password    requisite     pam_pwquality.so minlen=8 minclass=3 maxrepeat=3 enforce_for_root try_first_pass local_users_only retry=3 dcredit=0 ucredit=0 lcredit=0 ocredit=0
  ```

方法2：
- 在/etc/security/pwquality.conf文件中配置：

  ```bash
  # vim /etc/security/pwquality.conf
  maxrepeat = 3
  ```
