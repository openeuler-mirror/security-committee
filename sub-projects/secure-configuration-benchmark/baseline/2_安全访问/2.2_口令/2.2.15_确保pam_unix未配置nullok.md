### 2.2.15 确保pam_unix未配置nullok

**级别：** 要求

**适用版本：** 全部

**规则说明：**

nullok参数允许使用空口令的用户进行认证。如果pam_unix模块配置了nullok，则口令为空的用户可以无需输入口令直接登录系统，增加了系统被未授权访问的风险。应确保pam_unix模块未配置nullok参数。

**规则影响：**

口令为空的用户将无法登录系统，必须先设置口令。

**检查方法：**

- 使用如下命令检查pam_unix模块是否配置了nullok，以下命令应无输出：

  ```bash
  # grep nullok /etc/pam.d/system-auth /etc/pam.d/password-auth
  ```

**修复方法：**

编辑/etc/pam.d/system-auth和/etc/pam.d/password-auth文件，删除pam_unix.so行中的nullok参数。例如：

修改前：

```bash
auth        sufficient    pam_unix.so nullok try_first_pass
```

修改后：

```bash
auth        sufficient    pam_unix.so try_first_pass
```

同理，删除password行中的nullok参数。
