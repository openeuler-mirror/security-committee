### 2.6.3 确保全局加解密策略配置禁用不安全算法

**级别：** 要求

**适用版本：** 全部

**规则说明：** 

为保障系统传输与存储的密码学安全性，必须对操作系统全局加解密策略（Crypto-Policies）进行严格收紧。系统全局加密策略不得包含已被业界淘汰、存在安全缺陷或弱密码学特性的算法及模式，具体包括：

- 禁用 SHA-1 哈希及签名支持。

- 禁用长度小于 128 位的消息认证码（MAC）算法。

- 禁用 SSH 服务中的 CBC（密码块链接）加密模式。

- 禁用 SSH 服务中的 ChaCha20-Poly1305 算法（如果CVE-2023-48795的问题已得到解决，可以使用）。

- 禁用 SSH 服务中的 EtM（Encrypt-then-MAC）模式。

**规则影响：**

无

**检查方法：**

检查当前生效的crypto policy中是否已禁用不安全算法，依次验证以下各项：

1. 检查SHA-1哈希及签名是否已禁用：

```bash
# awk -F= '($1~/(hash|sign)/ && $2~/SHA1/ && $2!~/^\s*\\s*([^#\n\r]+)?SHA1/){print}' /etc/crypto-policies/state/CURRENT.pol
```

返回应为空。同时检查sha1_in_certs是否为0：

```bash
# grep -Psi -- '^\h*sha1_in_certs\h*=\h*' /etc/crypto-policies/state/CURRENT.pol
sha1_in_certs = 0
```

2. 检查长度小于128位的MAC算法是否已禁用：

```bash
# grep -Psi -- '^\h*mac@(lib|open)ssh(-server|-client)?\h*=\h*([^#\n\r]+)?\b(hmac-md5|hmac-md5-96|hmac-sha1-96|hmac-sha2-256-96|hmac-sha2-512-96)\b' /etc/crypto-policies/state/CURRENT.pol
```

返回应为空。

3. 检查SSH服务中CBC加密模式是否已禁用：

```bash
# grep -Psi -- '^\h*cipher@(lib|open)ssh(-server|-client)?\h*=\h*([^#\n\r]+)?-CBC\b' /etc/crypto-policies/state/CURRENT.pol
```

返回应为空。

4. 检查SSH服务中ChaCha20-Poly1305算法是否已禁用：

```bash
# grep -Psi -- '^\h*cipher@(lib|open)ssh(-server|-client)?\h*=\h*([^#\n\r]+)?chacha20-poly1305\b' /etc/crypto-policies/state/CURRENT.pol
```

返回应为空。

5. 检查SSH服务中EtM模式是否已禁用：

```bash
# grep -Psi -- '^\h*etm\b' /etc/crypto-policies/state/CURRENT.pol
```

返回应包含：

```
etm@libssh = DISABLE_ETM
etm@openssh-client = DISABLE_ETM
etm@openssh-server = DISABLE_ETM
```

或 `etm = DISABLE_ETM`。

**修复方法：**

通过创建子策略模块文件禁用不安全算法，然后应用该子策略。

1. 禁用SHA-1，创建子策略文件：

```bash
# printf '%s\n' "hash = -SHA1" "sign = -*-SHA1" "sha1_in_certs = 0" >> /etc/crypto-policies/policies/modules/NO-SHA1.pmod
```

2. 禁用长度小于128位的MAC算法，创建子策略文件：

```bash
# printf '%s\n' "mac@SSH = -HMAC-MD5 -HMAC-MD5-96 -HMAC-SHA1-96 -HMAC-SHA2-256-96 -HMAC-SHA2-512-96" >> /etc/crypto-policies/policies/modules/NO-SSHWEAKMACS.pmod
```

3. 禁用SSH的CBC模式，创建子策略文件：

```bash
# printf '%s\n' "cipher@SSH = -CBC" >> /etc/crypto-policies/policies/modules/NO-SSHCBC.pmod
```

4. 禁用SSH的ChaCha20-Poly1305算法，创建子策略文件：

```bash
# printf '%s\n' "cipher@SSH = -CHACHA20-POLY1305" >> /etc/crypto-policies/policies/modules/NO-SSHCHACHA20.pmod
```

5. 禁用SSH的EtM模式，创建子策略文件：

```bash
# printf '%s\n' "etm@SSH = DISABLE_ETM" >> /etc/crypto-policies/policies/modules/NO-SSHETM.pmod
```

6. 应用所有子策略：

```bash
# update-crypto-policies --set DEFAULT:NO-SHA1:NO-SSHWEAKMACS:NO-SSHCBC:NO-SSHCHACHA20:NO-SSHETM
```

7. 重启系统使配置生效：

```bash
# reboot
```

注：子策略文件名必须全部大写（如NO-SHA1.pmod），否则不会被读取。如果CVE-2023-48795的问题已得到解决且符合本地安全策略，可跳过ChaCha20-Poly1305和EtM的禁用。
