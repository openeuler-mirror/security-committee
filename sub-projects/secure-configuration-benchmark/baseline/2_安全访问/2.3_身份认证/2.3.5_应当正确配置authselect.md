### 2.3.5 应当正确配置authselect

**级别：** 建议

**适用版本：** 全部

**规则说明：** 

authselect是PAM配置管理工具，通过预置profile（如minimal、sssd、nis、winbind）统一管理/etc/pam.d/下的配置文件。使用authselect管理PAM配置可以避免手工编辑出错，确保配置一致性。

如果系统使用authselect管理PAM配置，应确保已选择有效的profile；如果系统使用传统方式（直接编辑/etc/pam.d/下文件）管理PAM配置，则本条不适用。

**规则影响：**

- 安全风险：使用authselect但未配置有效profile，可能导致PAM配置不完整或不一致，影响认证安全性。
- 配置影响：启用authselect会接管/etc/pam.d/下配置文件的管理，后续PAM配置变更需通过authselect命令完成，不能直接编辑。

**检查方法：**

检查authselect是否已安装：

```bash
# rpm -q authselect
authselect-<version>
```

如果已安装authselect，检查是否配置了有效profile：

```bash
# authselect current
Profile ID: minimal
Enabled features: with-faillock
```

如果输出为"No existing configuration detected"，表示authselect已安装但未激活，系统使用传统PAM配置方式，本条不适用。

**修复方法：**

如果需要使用authselect管理PAM配置，选择合适的profile并启用：

```bash
# authselect select minimal --with-faillock
```

可用的profile包括：
- minimal：仅本地用户
- sssd：启用SSSD认证
- nis：启用NIS认证
- winbind：启用Winbind认证

如果系统使用传统PAM配置方式（直接编辑/etc/pam.d/下文件），无需配置authselect，本条不适用。

**默认值：**

openEuler默认安装authselect但不激活，PAM配置使用传统方式管理。
