### 2.4.13 确保安装并正确配置sudo

**级别：** 要求

**适用版本：** 全部

**规则说明：**

sudo允许授权用户以其他用户身份执行命令，是Linux系统中进行权限提升的标准工具。系统应安装sudo并正确配置，主要包含以下方面：

- 安装sudo软件包。
- 配置sudo使用伪终端（use_pty），防止用户通过sudo执行的程序记录终端输入输出。
- 配置sudo认证超时时间（timestamp_timeout），避免sudo认证凭据长时间有效。
- 确保未全局禁用sudo重新认证（即未配置Defaults !authenticate），防止用户在执行sudo时无需认证。
- 限制su命令的使用权限，仅允许wheel组成员切换到root用户。

**规则影响：**

无

**检查方法：**

- 使用如下命令检查sudo是否已安装：

  ```bash
  # rpm -q sudo
  sudo-1.9.15p5-5.oe2403sp3.x86_64
  ```

- 使用如下命令检查sudo是否配置使用伪终端：

  ```bash
  # grep -E "^Defaults.*use_pty" /etc/sudoers /etc/sudoers.d/*
  Defaults use_pty
  ```

- 使用如下命令检查sudo认证超时时间是否已配置：

  ```bash
  # grep -E "^Defaults.*timestamp_timeout" /etc/sudoers /etc/sudoers.d/*
  Defaults timestamp_timeout=15
  ```

- 使用如下命令确认未全局禁用sudo重新认证，以下命令应无输出：

  ```bash
  # grep -E "^Defaults.*!authenticate" /etc/sudoers /etc/sudoers.d/*
  ```

- 使用如下命令检查su命令是否受限使用：

  ```bash
  # grep "pam_wheel" /etc/pam.d/su
  auth		required	pam_wheel.so use_uid
  ```

**修复方法：**

- 安装sudo：

  ```bash
  # yum install sudo
  ```
  或
  ```bash
  # dnf install sudo
  ```

- 在/etc/sudoers文件中添加或修改如下配置：

  ```bash
  Defaults use_pty
  Defaults timestamp_timeout=15
  ```

- 确保/etc/sudoers和/etc/sudoers.d/下未配置`Defaults !authenticate`，如有则删除。

- 修改/etc/pam.d/su文件，启用pam_wheel模块限制su命令使用：

  ```bash
  # vim /etc/pam.d/su
  auth		required	pam_wheel.so use_uid
  ```
