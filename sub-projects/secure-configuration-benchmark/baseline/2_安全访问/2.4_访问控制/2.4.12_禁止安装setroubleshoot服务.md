### 2.4.12 禁止安装setroubleshoot服务

**级别：** 要求

**适用版本：** 全部

**规则说明：** 

setroubleshoot 服务面向桌面端设计，旨在向用户直观展示 SELinux 拦截事件与配置错误。但在无图形界面的服务器环境中，该服务属于非必要组件，为保障系统性能与安全基线，服务器环境不得安装该服务。

**规则影响：**

无

**检查方法：**

可通过如下命令检查是否安装了setroubleshoot软件，如果命令返回“package setroubleshoot is not installed”，表示未安装：

```bash
# rpm -q "setroubleshoot"
package setroubleshoot is not installed
```

**修复方法：**

对于已经安装了setroubleshoot软件的系统，可以通过yum或dnf命令进行卸载：

```bash
# yum remove setroubleshoot
```
或
```bash
# dnf remove setroubleshoot
```
