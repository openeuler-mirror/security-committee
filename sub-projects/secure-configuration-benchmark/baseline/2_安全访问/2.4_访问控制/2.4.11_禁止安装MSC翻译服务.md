### 2.4.11 禁止安装MSC翻译服务

**级别：** 要求

**适用版本：** 全部

**规则说明：** 

mcstrans软件包的mcstransd守护进程会向请求信息的客户端进程提供类别标签信息，该标签转换的定义位于/etc/selinux/targeted/setrans.conf。由于此服务并不经常使用，因此将其删除可以减少系统中运行的潜在易受攻击代码的数量。

**规则影响：**

无

**检查方法：**

可通过如下命令检查是否安装了mcstrans软件，如果命令返回“package mcstrans is not installed”，表示未安装：

```bash
# rpm -q "mcstrans"
package mcstrans is not installed
```

**修复方法：**

对于已经安装了mcstrans软件的系统，可以通过yum或dnf命令进行卸载：

```bash
# yum remove mcstrans
```
或
```bash
# dnf remove mcstrans
```
