### 2.1.15 禁止存在GID为0的非root账号

**级别：** 要求

**适用版本：** 全部

**规则说明：**

GID为0的组是Linux系统中的超级管理员组，组名业界约定俗成为root。如果存在非root账号的主组GID为0，则该账号将拥有root组的权限，导致权限控制失效。

openEuler默认满足不存在GID为0的非root账号。

**规则影响：**

无

**检查方法：**

使用如下命令检查/etc/passwd中是否存在GID为0的非root账号，以下命令应无输出：

```bash
# awk -F: '($1!="root" && $4==0) {print $1, $4}' /etc/passwd
```

**修复方法：**

将对应账号的主组GID修改为非0值：

```bash
# usermod -g <new_gid> <username>
```
