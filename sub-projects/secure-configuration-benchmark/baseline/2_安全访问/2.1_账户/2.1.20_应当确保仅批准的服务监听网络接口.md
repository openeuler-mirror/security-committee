### 2.1.20 应当确保仅批准的服务监听网络接口

**级别：** 建议

**适用版本：** 全部

**规则说明：**

系统运行的服务若监听网络接口，会扩大攻击面。应定期审查系统中所有监听网络接口的服务，确保仅运行业务必需且经过批准的服务，关闭不需要的网络服务。

**规则影响：**

关闭不必要的服务可能影响依赖该服务的应用程序，关闭前需评估业务影响。

**检查方法：**

列出系统中所有监听网络接口的服务：

```bash
# ss -lntu
Netid  State   Recv-Q  Send-Q  Local Address:Port  Peer Address:Port  Process
udp    UNCONN  0       0       0.0.0.0:68          0.0.0.0:*          users:(("dhclient",pid=...))
tcp    LISTEN  0       128     0.0.0.0:22          0.0.0.0:*          users:(("sshd",pid=...))
```

人工审核输出结果，确认每个监听服务均为业务必需且经过批准。如果存在未经批准的服务监听网络接口，则不通过。

**修复方法：**

对于未经批准的网络服务，根据服务类型采取相应措施：

1. 如果服务不需要运行，停止并禁用该服务：

```bash
# systemctl stop <service_name>
# systemctl disable <service_name>
```

2. 如果服务需要运行但不需要监听网络接口，将其配置为仅监听本地回环地址（参考相关服务的配置条目，如1.2.34邮件传输代理仅本地模式）。
