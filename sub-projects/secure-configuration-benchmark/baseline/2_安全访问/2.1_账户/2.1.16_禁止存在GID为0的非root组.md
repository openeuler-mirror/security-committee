### 2.1.16 禁止存在GID为0的非root组

**级别：** 要求

**适用版本：** 全部

**规则说明：**

GID为0的组拥有系统最高权限，系统中只应有root组的GID为0。如果存在其他组的GID为0，则该组成员将获得root组权限，导致权限提升风险。

openEuler默认满足不存在GID为0的非root组。

**规则影响：**

无

**检查方法：**

使用如下命令检查/etc/group中是否存在GID为0的非root组，以下命令应无输出：

```bash
# awk -F: '($1!="root" && $3==0) {print $1, $3}' /etc/group
```

**修复方法：**

修改对应组的GID为非0值：

```bash
# groupmod -g <new_gid> <groupname>
```
