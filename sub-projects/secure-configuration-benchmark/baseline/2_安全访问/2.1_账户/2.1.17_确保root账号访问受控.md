### 2.1.17 确保root账号访问受控

**级别：** 要求

**适用版本：** 全部

**规则说明：**

root账号是Linux系统的超级管理员账号，应确保root账号的登录权限受控。root账号默认应仅允许从受信任的终端登录，不应允许root账号通过不安全的远程方式直接登录系统。

openEuler默认禁止root用户通过SSH直接登录。

**规则影响：**

无

**检查方法：**

- 使用如下命令检查root账号的登录shell是否为有效shell：

  ```bash
  # awk -F: '($1=="root") {print $7}' /etc/passwd
  /bin/bash
  ```

- 使用如下命令检查SSH是否禁止root直接登录：

  ```bash
  # grep "^PermitRootLogin" /etc/ssh/sshd_config
  PermitRootLogin no
  ```

- 使用如下命令检查root账号的口令是否已设置（非空且非锁定）：

  ```bash
  # passwd -S root
  root PS 2024-01-01 0 99999 7 -1 (Password set, SHA512 crypt.)
  ```

**修复方法：**

- 修改/etc/ssh/sshd_config文件，禁止root通过SSH直接登录，重启sshd服务：

  ```bash
  # vim /etc/ssh/sshd_config
  PermitRootLogin no
  # systemctl restart sshd
  ```

- 确保root账号口令已设置且未被锁定。
