### 2.1.19 确保本地交互用户dot文件访问权限配置正确

**级别：** 要求

**适用版本：** 全部

**规则说明：**

用户Home目录下的dot文件（如.bashrc、.bash_profile、.profile等）在用户登录时自动加载执行。如果这些文件的权限设置不当（如其他用户可写），攻击者可以修改dot文件注入恶意命令，在用户登录时以该用户身份执行。

建议dot文件权限不超过600（仅属主可读写），dot目录权限不超过700（仅属主可读写执行）。

**规则影响：**

无

**检查方法：**

使用如下命令检查本地交互用户Home目录下dot文件和dot目录的权限，返回结果中权限超过限制的文件需修复：

```bash
# for home in $(awk -F: '($7 !~ /(nologin|false)$/ && $3 >= 1000) {print $6}' /etc/passwd); do
    if [ -d "$home" ]; then
      find "$home" -name ".*" \( -perm /g+w -o -perm /o+w \) -ls 2>/dev/null
    fi
  done
```

**修复方法：**

对于权限不当的dot文件，修改权限为600：

```bash
# chmod 600 <dotfile>
```

对于权限不当的dot目录，修改权限为700：

```bash
# chmod 700 <dotdir>
```
