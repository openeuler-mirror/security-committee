### 3.5.24 确保不接受ipv6路由器通告

**级别：** 要求

**适用版本：** 全部

**规则说明：**

IPv6路由器通告（Router Advertisement，RA）用于自动配置主机的IPv6地址和默认路由。接受来自链路的RA可能导致系统使用攻击者伪造的路由信息，将流量重定向到恶意节点。

通过将net.ipv6.conf.all.accept_ra和net.ipv6.conf.default.accept_ra设置为0，系统不会接受IPv6路由器通告。

**规则影响：**

系统不接收IPv6路由器通告，需手动配置IPv6地址和默认路由。

**检查方法：**

首先，检查当前系统内核参数的设置。输入命令查看返回值是否为0：

```bash
# sysctl net.ipv6.conf.all.accept_ra net.ipv6.conf.default.accept_ra
net.ipv6.conf.all.accept_ra = 0
net.ipv6.conf.default.accept_ra = 0
```

其次，执行如下命令，如果返回值不为0，表示配置不正确，建议修改配置文件内容。如果返回值为空，表示系统使用默认配置。

```bash
# grep "net.ipv6.conf.all.accept_ra" /etc/sysctl.conf /etc/sysctl.d/*
net.ipv6.conf.all.accept_ra=0
# grep "net.ipv6.conf.default.accept_ra" /etc/sysctl.conf /etc/sysctl.d/*
net.ipv6.conf.default.accept_ra=0
```

**修复方法：**

输入命令禁止接受IPv6路由器通告：

```bash
# sysctl -w net.ipv6.conf.all.accept_ra=0
# sysctl -w net.ipv6.conf.default.accept_ra=0
```

修改/etc/sysctl.conf文件，添加或修改配置：

```bash
net.ipv6.conf.all.accept_ra=0
net.ipv6.conf.default.accept_ra=0
```
