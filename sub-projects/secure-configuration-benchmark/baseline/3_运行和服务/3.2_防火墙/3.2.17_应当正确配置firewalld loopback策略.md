### 3.2.17 应当正确配置firewalld loopback策略

**级别：** 建议

**适用版本：** 全部

**规则说明：**

回环接口（lo）用于本机进程间通信，应允许回环接口上的所有流量。但不应从其他网络接口接收源地址为127.0.0.0/8（IPv4）或::1（IPv6）的报文，此类报文属于地址欺骗，应予以拒绝。

如果回环地址策略配置不当，可能导致本机进程间通信失败，或遭受来自外部网络的地址欺骗攻击。

**规则影响：**

无

**检查方法：**

- 使用如下命令检查回环接口流量是否被允许，如果trusted区域包含lo接口，表示配置正确：

  ```bash
  # firewall-cmd --zone=trusted --list-interfaces
  lo
  ```

- 使用如下命令检查是否存在拒绝外部接口回环地址欺骗的富规则：

  ```bash
  # firewall-cmd --list-rich-rules
  rule family='ipv4' source address='127.0.0.0/8' drop
  rule family='ipv6' source address='::1' drop
  ```

**修复方法：**

将回环接口添加到trusted区域，允许回环接口上的所有流量：

```bash
# firewall-cmd --permanent --zone=trusted --add-interface=lo
```

添加富规则，拒绝从其他接口进入的回环地址欺骗报文：

```bash
# firewall-cmd --permanent --add-rich-rule='rule family=ipv4 source address=127.0.0.0/8 drop'
# firewall-cmd --permanent --add-rich-rule='rule family=ipv6 source address=::1 drop'
```

重新加载防火墙配置使其生效：

```bash
# firewall-cmd --reload
```
