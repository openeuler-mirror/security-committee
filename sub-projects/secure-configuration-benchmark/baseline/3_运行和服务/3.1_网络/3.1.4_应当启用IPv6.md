### 3.1.4 应当启用IPv6

**级别：** 建议

**适用版本：** 全部

**规则说明：**

IPv6是互联网协议的下一代标准，现代系统和服务逐步依赖IPv6进行通信。禁用IPv6可能导致部分网络功能异常，且不利于向IPv6网络的迁移。建议保持IPv6启用状态，如无明确业务需求不应禁用。

openEuler默认启用IPv6。

**规则影响：**

无

**检查方法：**

- 检查sysctl配置确认IPv6未被禁用：

```bash
# sysctl net.ipv6.conf.all.disable_ipv6
net.ipv6.conf.all.disable_ipv6 = 0
```

- 检查grub引导参数中未设置ipv6.disable=1：

```bash
# grubby --info=ALL | grep -Po 'ipv6\.disable=1\b'
```

应无输出。

**修复方法：**

- 如果sysctl中禁用了IPv6，修改/etc/sysctl.conf或/etc/sysctl.d/下配置文件，将`net.ipv6.conf.all.disable_ipv6`设为0，并执行`sysctl -p`生效：

```bash
# vim /etc/sysctl.conf
net.ipv6.conf.all.disable_ipv6 = 0
# sysctl -p
```

- 如果grub引导参数中包含`ipv6.disable=1`，移除该参数：

```bash
# grubby --update-kernel=ALL --remove-args="ipv6.disable=1"
```
