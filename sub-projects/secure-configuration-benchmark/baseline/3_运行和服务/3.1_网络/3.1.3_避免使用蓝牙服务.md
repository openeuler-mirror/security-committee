### 3.1.3 避免使用蓝牙服务

**级别：** 建议

**适用版本：** 全部

**规则说明：**

蓝牙服务提供短距离无线通信功能，服务器场景下通常不需要蓝牙功能。开启蓝牙服务会增加系统的攻击面，攻击者可能利用蓝牙协议漏洞进行未授权访问或信息窃取。

如系统不需要蓝牙功能，建议移除蓝牙相关软件包。

openEuler默认未安装bluez软件包。

**规则影响：**

移除蓝牙服务后，系统将无法使用蓝牙设备进行通信。

**检查方法：**

- 使用如下命令检查是否安装了bluez软件，如果命令返回为"package bluez is not installed"，表示未安装：

  ```bash
  # rpm -q bluez
  package bluez is not installed
  ```

- 如果bluez已安装，可通过如下命令检查蓝牙服务是否未启用：

  ```bash
  # systemctl is-enabled bluetooth.service
  disabled
  ```

**修复方法：**

对于已安装bluez的系统，可以通过yum或dnf命令进行卸载：

```bash
# yum remove bluez
```
或
```bash
# dnf remove bluez
```
