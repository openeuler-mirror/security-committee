### 3.3.21 确保禁用SSH的TCP转发功能

**级别：** 要求

**适用版本：** 全部

**规则说明：** 

SSH转发功能包括TCP端口转发、X11转发、ssh-agent转发和StreamLocal（Unix域套接字）转发。禁用这些转发功能可以限制用户在SSH会话中的数据传输和访问范围，从而增强系统的安全性。

- AllowTcpForwarding：禁止SSH客户端进行TCP端口转发，防止通过SSH隧道在本地主机和远程主机之间传输数据。
- AllowAgentForwarding：禁止ssh-agent转发，防止用户私钥通过SSH连接转发到远程主机，降低私钥泄露风险。
- AllowStreamLocalForwarding：禁止Unix域套接字转发，防止通过SSH隧道转发本地套接字连接。

**规则影响：**

禁用转发功能可能会影响某些应用和用例，例如需要远程访问受限服务、使用ssh-agent单点登录或Unix域套接字转发的场景。

**检查方法：**

执行以下命令，验证SSH的转发配置是否正确：

```bash
# sshd -T -C user=root -C host="$(hostname)" -C addr="$(grep $(hostname) /etc/hosts | awk '{print $1}')" | grep -E "allowtcpforwarding|allowagentforwarding|allowstreamlocalforwarding"
allowagentforwarding no
allowstreamlocalforwarding no
allowtcpforwarding no
```

也可通过grep命令逐一检查：

```bash
# grep -Ei '^\s*AllowTcpForwarding\s+yes\b' /etc/ssh/sshd_config
Nothing is returned
# grep -Ei '^\s*AllowAgentForwarding\s+yes\b' /etc/ssh/sshd_config
Nothing is returned
# grep -Ei '^\s*AllowStreamLocalForwarding\s+yes\b' /etc/ssh/sshd_config
Nothing is returned
```

**修复方法：**

编辑/etc/ssh/sshd_config配置文件，添加或修改以下参数：

```bash
# vim /etc/ssh/sshd_config
AllowTcpForwarding no
AllowAgentForwarding no
AllowStreamLocalForwarding no
# systemctl restart sshd
```
