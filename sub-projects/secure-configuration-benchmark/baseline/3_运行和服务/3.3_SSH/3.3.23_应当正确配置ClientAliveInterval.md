### 3.3.23 应当正确配置ClientAliveInterval

**级别：** 建议

**适用版本：** 全部

**规则说明：**

ClientAliveInterval设置SSH服务端向客户端发送存活检测消息的时间间隔（秒）。当该值大于0时，如果超过该时间未收到客户端数据，sshd会发送请求响应的消息。ClientAliveCountMax设置sshd在未收到响应时发送存活检测消息的最大次数，超过此次数后断开连接。

合理配置这两个参数可以自动断开空闲的SSH连接，防止未授权人员利用空闲会话操作系统。

**规则影响：**

空闲的SSH连接将在超时后被自动断开。

**检查方法：**

使用grep命令查看配置：

```bash
# grep -i "^ClientAliveInterval" /etc/ssh/sshd_config
ClientAliveInterval 900
# grep -i "^ClientAliveCountMax" /etc/ssh/sshd_config
ClientAliveCountMax 0
```

**修复方法：**

修改/etc/ssh/sshd_config文件，配置ClientAliveInterval和ClientAliveCountMax字段，重启sshd服务：

```bash
# vim /etc/ssh/sshd_config
ClientAliveInterval 900
ClientAliveCountMax 0
# systemctl restart sshd
```
