### 3.3.24 禁止使用GSSAPIAuthentication

**级别：** 要求

**适用版本：** 全部

**规则说明：**

GSSAPIAuthentication允许SSH使用GSSAPI（通用安全服务应用程序接口）进行身份验证。启用该功能会增加系统的攻击面，可能被利用进行未授权访问。如无Kerberos等GSSAPI认证需求，应禁用该功能。

openEuler默认禁用GSSAPIAuthentication。

**规则影响：**

禁用后，SSH将不支持基于GSSAPI的认证方式。

**检查方法：**

使用grep命令查看配置：

```bash
# grep -i "^GSSAPIAuthentication" /etc/ssh/sshd_config
GSSAPIAuthentication no
```

**修复方法：**

修改/etc/ssh/sshd_config文件，配置GSSAPIAuthentication字段为no，重启sshd服务：

```bash
# vim /etc/ssh/sshd_config
GSSAPIAuthentication no
# systemctl restart sshd
```
