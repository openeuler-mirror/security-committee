### 4.3.1 确保journald服务已启用并运行

**级别：** 要求

**适用版本：** 全部

**规则说明：**

systemd-journald是systemd的日志服务组件，负责收集和存储系统日志。journald支持结构化日志、日志压缩和日志转发等功能。确保journald服务正常运行，是系统日志可用的基础保障。同时应确保日志文件的访问权限受到合理控制，防止未授权用户读取或篡改日志。

**规则影响：**

无

**检查方法：**

- 执行如下命令，查看systemd-journald服务是否已经启动：

  ```bash
  # systemctl status systemd-journald.service | grep Active
  Active: active (running) since Mon 2024-01-01 08:00:00 CST; 1 day ago
  ```

- 执行如下命令，确认日志可以正常查询：

  ```bash
  # journalctl --boot=0 | tail -1
  ```

- 确认journald日志存储模式为persistent，确保日志持久化存储并受权限保护：

  ```bash
  # grep "^Storage" /etc/systemd/journald.conf
  Storage=persistent
  ```

- 确认/var/log/journal/目录权限为2755、属主为root、属组为systemd-journal：

  ```bash
  # ls -ld /var/log/journal/
  drwxr-sr-x. 2 root systemd-journal 4096 Jan  1 08:00 /var/log/journal/
  ```

**修复方法：**

启动并启用systemd-journald服务：

```bash
# systemctl start systemd-journald.service
# systemctl enable systemd-journald.service
```

如果Storage未配置为persistent，修改/etc/systemd/journald.conf：

```bash
# vim /etc/systemd/journald.conf
Storage=persistent
```

修改后重启服务：

```bash
# systemctl restart systemd-journald.service
```
