### 4.3.3 确保系统中仅使用一种日志服务

**级别：** 建议

**适用版本：** 全部

**规则说明：**

系统可能同时安装了rsyslog和systemd-journald两种日志服务。同时运行多种日志服务可能导致日志记录重复、资源浪费，且增加管理复杂度。应选择一种日志服务作为主要日志记录方式，另一种仅作为辅助或关闭。

通常建议使用rsyslog作为主要日志服务，journald作为systemd组件保持运行但不转发日志给rsyslog。

**规则影响：**

无

**检查方法：**

- 使用如下命令确认rsyslog服务状态：

  ```bash
  # systemctl is-enabled rsyslog.service
  enabled
  ```

- 使用如下命令确认journald服务状态：

  ```bash
  # systemctl is-active systemd-journald.service
  active
  ```

- 确认日志转发配置是否与选定的日志策略一致：

  ```bash
  # grep "^ForwardToSyslog" /etc/systemd/journald.conf
  ForwardToSyslog=no
  ```

**修复方法：**

根据业务场景选择主日志服务，若以rsyslog为主，则在journald配置中关闭日志转发；若以journald为主，则可关闭rsyslog服务。

- 以rsyslog为主时，编辑/etc/systemd/journald.conf：

  ```bash
  # vim /etc/systemd/journald.conf
  ForwardToSyslog=no
  ```

  重启journald服务：

  ```bash
  # systemctl restart systemd-journald.service
  ```
