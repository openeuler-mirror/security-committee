### 4.3.4 确保正确配置systemd-journal-remote服务

**级别：** 建议

**适用版本：** 全部

**规则说明：**

systemd-journal-remote提供日志远程传输功能，包含journal-upload（上传端）和journal-remote（接收端）两个组件。对于非日志服务器，不应启用journal-remote接收端服务；如需将日志转发至远程日志服务器，应安装并配置journal-upload，并确保使用TLS认证。

openEuler默认未安装systemd-journal-remote软件包。

**规则影响：**

启用日志远程传输会增加网络通信开销。

**检查方法：**

- 使用如下命令检查是否安装了systemd-journal-remote：

  ```bash
  # rpm -q systemd-journal-remote
  package systemd-journal-remote is not installed
  ```

- 如果已安装，检查journal-remote接收端服务是否未启用：

  ```bash
  # systemctl is-enabled systemd-journal-remote.service
  disabled
  ```

- 如果已配置日志上传，检查journal-upload服务是否启用：

  ```bash
  # systemctl is-enabled systemd-journal-upload.service
  enabled
  ```

**修复方法：**

- 对于需要将日志转发至远程日志服务器的系统，安装并配置systemd-journal-remote：

  ```bash
  # yum install systemd-journal-remote
  ```
  或
  ```bash
  # dnf install systemd-journal-remote
  ```

- 编辑/etc/systemd/journal-upload.conf配置远程日志服务器地址和TLS认证：

  ```bash
  # vim /etc/systemd/journal-upload.conf
  [Upload]
  URL=https://<log-server>:19532
  ```

- 启用并启动journal-upload服务：

  ```bash
  # systemctl enable --now systemd-journal-upload.service
  ```

- 对于非日志服务器，确保journal-remote接收端服务未启用：

  ```bash
  # systemctl disable --now systemd-journal-remote.service
  ```
