### 4.3.5 确保journald的ForwardToSyslog已禁用

**级别：** 建议

**适用版本：** 全部

**规则说明：**

ForwardToSyslog控制journald是否将日志消息转发给rsyslog。如果系统以journald作为主要日志服务，且rsyslog未运行或不需要接收日志，应禁用该选项，避免不必要的日志转发开销和重复记录。

**规则影响：**

禁用后，rsyslog将不再从journald接收日志消息。

**检查方法：**

使用如下命令检查ForwardToSyslog配置：

```bash
# grep "^ForwardToSyslog" /etc/systemd/journald.conf
ForwardToSyslog=no
```

如果命令无输出，表示使用默认配置（默认为yes）。

**修复方法：**

编辑/etc/systemd/journald.conf文件，配置ForwardToSyslog为no：

```bash
# vim /etc/systemd/journald.conf
ForwardToSyslog=no
```

修改后重启systemd-journald服务：

```bash
# systemctl restart systemd-journald.service
```
