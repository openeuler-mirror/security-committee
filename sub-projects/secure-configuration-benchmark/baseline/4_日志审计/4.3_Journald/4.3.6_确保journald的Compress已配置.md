### 4.3.6 确保journald的Compress已配置

**级别：** 建议

**适用版本：** 全部

**规则说明：**

Compress参数控制journald是否对日志数据进行压缩存储。启用压缩可以减少日志占用的磁盘空间，尤其在日志量较大的场景下效果显著。建议启用日志压缩。

openEuler默认启用日志压缩。

**规则影响：**

启用压缩会增加少量CPU开销，但可节省磁盘空间。

**检查方法：**

使用如下命令检查Compress配置：

```bash
# grep "^Compress" /etc/systemd/journald.conf
Compress=yes
```

如果命令无输出，表示使用默认配置（默认为yes）。

**修复方法：**

编辑/etc/systemd/journald.conf文件，配置Compress为yes：

```bash
# vim /etc/systemd/journald.conf
Compress=yes
```

修改后重启systemd-journald服务：

```bash
# systemctl restart systemd-journald.service
```
