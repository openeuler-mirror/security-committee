### 4.3.7 确保journald的Storage已配置

**级别：** 要求

**适用版本：** 全部

**规则说明：**

Storage参数控制journald日志的存储方式。可选值包括：
- volatile：日志仅存储在内存中，重启后丢失
- persistent：日志存储在磁盘上，重启后保留
- auto：如果/var/log/journal目录存在则存储到磁盘，否则仅存储在内存中
- none：不存储任何日志

建议将Storage设置为persistent，确保日志在系统重启后保留，便于事后审计和问题排查。

**规则影响：**

日志将持久化存储到磁盘，占用一定的磁盘空间。

**检查方法：**

使用如下命令检查Storage配置：

```bash
# grep "^Storage" /etc/systemd/journald.conf
Storage=persistent
```

如果命令无输出，表示使用默认配置（默认为auto）。检查日志目录是否存在：

```bash
# ls -ld /var/log/journal/
drwxr-sr-x. 3 root systemd-journal 4096 Jan  1 08:00 /var/log/journal/
```

**修复方法：**

- 创建日志目录（如不存在）：

  ```bash
  # mkdir -p /var/log/journal
  # systemctl restart systemd-journald.service
  ```

- 编辑/etc/systemd/journald.conf文件，配置Storage为persistent：

  ```bash
  # vim /etc/systemd/journald.conf
  Storage=persistent
  ```

  修改后重启systemd-journald服务：

  ```bash
  # systemctl restart systemd-journald.service
  ```
