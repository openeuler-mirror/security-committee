### 4.3.2 确保journald日志文件轮转配置正确

**级别：** 建议

**适用版本：** 全部

**规则说明：**

journald日志会持续增长，应配置日志轮转策略以防止日志占满磁盘空间。通过配置SystemMaxUse、SystemKeepFree、RuntimeMaxUse和MaxFileSec等参数，可以控制日志文件的最大占用空间、保留可用磁盘空间以及日志文件的最大保留时间。

**规则影响：**

超过保留时间或空间限制的日志将被自动清理。

**检查方法：**

使用如下命令检查journald日志轮转相关配置：

```bash
# grep -E "^SystemMaxUse|^SystemKeepFree|^RuntimeMaxUse|^MaxFileSec" /etc/systemd/journald.conf
SystemMaxUse=100M
SystemKeepFree=50M
RuntimeMaxUse=50M
MaxFileSec=1month
```

如果以上命令无输出，表示使用默认配置。可通过如下命令查看当前日志占用情况：

```bash
# journalctl --disk-usage
Archived and active journals take up 8.0M on disk.
```

**修复方法：**

编辑/etc/systemd/journald.conf文件，配置日志轮转参数：

```bash
# vim /etc/systemd/journald.conf
SystemMaxUse=100M
SystemKeepFree=50M
RuntimeMaxUse=50M
MaxFileSec=1month
```

修改后重启systemd-journald服务：

```bash
# systemctl restart systemd-journald.service
```
