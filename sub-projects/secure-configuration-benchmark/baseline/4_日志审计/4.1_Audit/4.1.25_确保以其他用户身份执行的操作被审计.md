### 4.1.25 确保以其他用户身份执行的操作被审计

**级别：** 建议

**适用版本：** 全部

**规则说明：**

用户通过sudo、su等命令以其他用户身份执行操作时，应记录审计日志。此类操作涉及权限切换，是安全事件追溯的重要依据。

openEuler默认不配置此审计规则，建议用户根据实际业务场景配置。

**规则影响：**

配置审计后，权限切换操作时会记录审计日志，对性能有轻微影响。

**检查方法：**

通过如下命令检查以其他用户身份执行操作的审计规则：

```bash
# auditctl -l | grep -E "sudo|su|pkexec"
-a always,exit -F path=/usr/bin/sudo -F perm=x -F auid>=1000 -F auid!=-1 -F key=privileged
-a always,exit -F path=/usr/bin/su -F perm=x -F auid>=1000 -F auid!=-1 -F key=privileged
-a always,exit -F path=/usr/bin/pkexec -F perm=x -F auid>=1000 -F auid!=-1 -F key=privileged
```

**修复方法：**

在/etc/audit/rules.d/目录下新建或修改规则文件，添加审计规则：

```bash
# vim /etc/audit/rules.d/privileged.rules
-a always,exit -F path=/usr/bin/sudo -F perm=x -F auid>=1000 -F auid!=unset -k privileged
-a always,exit -F path=/usr/bin/su -F perm=x -F auid>=1000 -F auid!=unset -k privileged
-a always,exit -F path=/usr/bin/pkexec -F perm=x -F auid>=1000 -F auid!=unset -k privileged
```

重启auditd服务，使规则生效：

```bash
# service auditd restart
```
