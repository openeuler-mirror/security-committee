### 4.1.23 确保使用加密机制保护审计工具完整性

**级别：** 建议

**适用版本：** 全部

**规则说明：**

AIDE使用加密哈希算法（如SHA256、SHA512等）来计算和存储文件校验值，确保文件完整性检查结果可信。应确保AIDE配置使用了强加密哈希算法，而非弱算法（如MD5、SHA1）。

**规则影响：**

无

**检查方法：**

- 使用如下命令检查AIDE配置中是否使用了强哈希算法：

  ```bash
  # grep -E "sha256|sha512|mhash|crc32" /etc/aide.conf
  sha256=true
  sha512=true
  ```

- 确保未使用弱哈希算法，以下命令应无输出或输出行中未启用：

  ```bash
  # grep -E "^md5=true|^sha1=true" /etc/aide.conf
  ```

**修复方法：**

编辑/etc/aide.conf文件，启用强哈希算法，禁用弱哈希算法：

```bash
# vim /etc/aide.conf
sha256=true
sha512=true
md5=false
sha1=false
```

修改后重新初始化AIDE数据库：

```bash
# aide --init
# mv /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz
```
