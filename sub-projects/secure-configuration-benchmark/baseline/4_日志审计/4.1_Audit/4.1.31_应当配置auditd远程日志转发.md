### 4.1.31 应当配置auditd远程日志转发

**级别：** 建议

**适用版本：** 全部

**规则说明：** 

auditd支持通过au-remote插件将审计日志发送到远程日志服务器，实现审计日志的集中存储和异地备份。配置涉及以下文件：

- /etc/audit/plugins.d/au-remote.conf：控制au-remote插件的启用状态，需设置active = yes。
- /etc/audit/auditd.conf：配置远程日志服务器地址，需设置remote_server参数。

将审计日志发送到远程服务器可以防止攻击者在本地篡改或删除审计日志，确保审计记录的完整性和可追溯性。

openEuler默认不配置auditd远程日志转发。

**规则影响：**

- 安全风险：不配置远程日志转发，审计日志仅存储在本地，攻击者可能篡改或删除本地日志以掩盖攻击痕迹。
- 配置影响：需确保远程日志服务器有足够的存储空间和网络带宽接收审计日志，并保障传输通道安全。

**检查方法：**

检查au-remote插件是否启用：

```bash
# grep -i "active" /etc/audit/plugins.d/au-remote.conf
active = yes
```

检查远程日志服务器是否已配置：

```bash
# grep -i "remote_server" /etc/audit/auditd.conf
remote_server = <remote_log_host>
```

如果au-remote.conf文件不存在或active未设置为yes，且remote_server未配置，则表示未配置auditd远程日志转发。

**修复方法：**

1. 编辑/etc/audit/plugins.d/au-remote.conf，启用au-remote插件：

```bash
# vim /etc/audit/plugins.d/au-remote.conf
active = yes
direction = out
path = /sbin/audisp-remote
type = always
args = /etc/audit/audisp-remote.conf
format = string
```

2. 编辑/etc/audit/auditd.conf，配置远程日志服务器地址：

```bash
# vim /etc/audit/auditd.conf
remote_server = <remote_log_host>
```

3. 根据需要编辑/etc/audit/audisp-remote.conf，配置远程传输参数（如端口、队列大小等）。

4. 重启auditd服务使配置生效：

```bash
# service auditd restart
```
