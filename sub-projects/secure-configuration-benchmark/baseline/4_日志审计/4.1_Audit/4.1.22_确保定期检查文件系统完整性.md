### 4.1.22 确保定期检查文件系统完整性

**级别：** 建议

**适用版本：** 全部

**规则说明：**

AIDE（Advanced Intrusion Detection Environment）是一种文件完整性检查工具，通过对比文件属性和内容的哈希值来检测文件是否被篡改。应配置AIDE定期执行完整性检查，及时发现系统文件的未授权修改。

openEuler默认未安装AIDE。

**规则影响：**

AIDE的初始化和定期检查会消耗一定的系统资源和磁盘空间。

**检查方法：**

- 使用如下命令检查AIDE是否已安装：

  ```bash
  # rpm -q aide
  aide-0.18.6-3.h6.eulerosv2r15.x86_64
  ```

- 使用如下命令检查是否配置了AIDE定时任务：

  ```bash
  # crontab -l | grep aide
  0 5 * * * /usr/sbin/aide --check
  ```

  或检查是否存在systemd定时器：

  ```bash
  # systemctl is-enabled aidecheck.timer
  enabled
  ```

**修复方法：**

- 安装AIDE：

  ```bash
  # yum install aide
  ```
  或
  ```bash
  # dnf install aide
  ```

- 初始化AIDE数据库：

  ```bash
  # aide --init
  # mv /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz
  ```

- 配置定时任务，例如每天凌晨5点执行检查：

  ```bash
  # (crontab -l 2>/dev/null; echo "0 5 * * * /usr/sbin/aide --check") | crontab -
  ```
