### 4.1.29 确保usermod命令的使用被审计

**级别：** 建议

**适用版本：** 全部

**规则说明：**

usermod命令用于修改用户账号属性，包括登录shell、主组、附加组、UID等，属于账号管理特权操作。对usermod命令的成功和失败调用都应记录审计日志，以便事后追溯账号属性的变更。

openEuler默认不配置此审计规则，建议用户根据实际业务场景配置。

**规则影响：**

配置审计后，usermod命令执行时会记录审计日志，对性能有轻微影响。

**检查方法：**

通过如下命令检查usermod命令的审计规则：

```bash
# auditctl -l | grep usermod
-a always,exit -F path=/usr/sbin/usermod -F perm=x -F auid>=1000 -F auid!=-1 -F key=privileged
```

**修复方法：**

在/etc/audit/rules.d/目录下新建或修改规则文件，添加审计规则：

```bash
# vim /etc/audit/rules.d/privileged.rules
-a always,exit -F path=/usr/sbin/usermod -F perm=x -F auid>=1000 -F auid!=unset -k privileged
```

重启auditd服务，使规则生效：

```bash
# service auditd restart
```
