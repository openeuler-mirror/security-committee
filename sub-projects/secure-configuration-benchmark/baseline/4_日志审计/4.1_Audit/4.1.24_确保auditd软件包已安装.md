### 4.1.24 确保auditd软件包已安装

**级别：** 要求

**适用版本：** 全部

**规则说明：**

auditd是Linux审计框架的用户空间组件，提供系统安全审计日志的收集、存储和查询功能。系统应安装auditd相关软件包，确保审计功能可用。

openEuler默认安装audit软件包。

**规则影响：**

无

**检查方法：**

使用如下命令检查auditd软件包是否已安装：

```bash
# rpm -q audit
audit-3.0.7-7.oe2403sp3.x86_64
```

**修复方法：**

对于未安装audit的系统，可以通过yum或dnf命令进行安装：

```bash
# yum install audit
```
或
```bash
# dnf install audit
```

安装后启用并启动auditd服务：

```bash
# systemctl enable auditd.service
# systemctl start auditd.service
```
