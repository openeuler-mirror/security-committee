### 4.1.30 确保运行中的审计配置与磁盘上的配置一致

**级别：** 要求

**适用版本：** 全部

**规则说明：**

审计规则的运行时配置应与磁盘上的配置文件保持一致。如果运行时配置与磁盘配置不同，说明审计规则可能被临时修改，系统重启后规则将恢复为磁盘配置，导致审计规则不一致。

**规则影响：**

无

**检查方法：**

使用如下命令对比运行时配置与磁盘配置是否一致，如果输出为空表示一致：

```bash
# diff <(auditctl -l | grep -v "^No rules") /etc/audit/rules.d/*.rules
```

也可通过augencheck命令检查（如可用）：

```bash
# augenrules --check
```

**修复方法：**

如果运行时配置与磁盘配置不一致，应将磁盘配置加载为运行时配置：

```bash
# augenrules --load
```

或重启auditd服务：

```bash
# service auditd restart
```
