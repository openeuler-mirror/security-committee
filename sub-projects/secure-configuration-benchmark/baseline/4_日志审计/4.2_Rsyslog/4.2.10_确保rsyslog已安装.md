### 4.2.10 确保rsyslog已安装

**级别：** 要求

**适用版本：** 全部

**规则说明：**

rsyslog是Linux系统标准的日志服务，负责收集、处理和存储系统日志。系统应安装rsyslog，确保日志能够持久化存储和集中管理。

openEuler默认安装rsyslog。

**规则影响：**

无

**检查方法：**

使用如下命令检查rsyslog是否已安装：

```bash
# rpm -q rsyslog
rsyslog-8.2312.0-9.oe2403sp3.x86_64
```

**修复方法：**

对于未安装rsyslog的系统，可以通过yum或dnf命令进行安装：

```bash
# yum install rsyslog
```
或
```bash
# dnf install rsyslog
```

安装后启用并启动rsyslog服务：

```bash
# systemctl enable rsyslog.service
# systemctl start rsyslog.service
```
