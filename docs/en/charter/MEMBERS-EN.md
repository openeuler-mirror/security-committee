## Members

English | [简体中文](../../../MEMBERS.md)

SC members develop openEuler security standards and processes. Their work covers the security of package intake, builds, and releases, as well as vulnerability management. Members must pass the [openEuler community security awareness exam](https://www.openeuler.org/zh/blog/openeuler/20240428-security.html).
